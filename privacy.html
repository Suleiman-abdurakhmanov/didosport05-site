2. Какие данные мы собираем

2.1. Данные, которые вы предоставляете добровольно

  • Сообщение через форму «Связаться» — текст обращения и тема, которые вы сами пишете перед переходом в Telegram. Эти данные не сохраняются на Сайте: кнопка открывает Telegram с уже заполненным сообщением.
  • Донат — при переводе через СБП/Сбербанк мы получаем только номер телефона получателя. Сайт не запрашивает и не сохраняет данные вашей карты.

2.2. Данные, которые собираются автоматически

  • Cookie и localStorage — используются исключительно для запоминания ваших действий на Сайте (отметки «нравится», выбранный язык). Эти данные хранятся только в вашем браузере и не передаются третьим лицам.
  • Анонимная статистика посещений — IP-адрес (в обезличенном виде), тип браузера, операционная система, время визита. Собирается счётчиком Яндекс.Метрикой для аналитики посещаемости.
  • Рекламные cookie — если на Сайте размещены блоки Яндекс.РСЯ, эти системы могут устанавливать собственные cookie для показа релевантной рекламы и учёта показов.

3. Цели обработки данных

  • Ответ на обращение через Telegram (только по вашему запросу).
  • Приём пожертвований на развитие сообщества.
  • Улучшение работы Сайта на основе обезличенной статистики посещений.
  • Монетизация Сайта через рекламные сети (Яндекс.РСЯ) для покрытия расходов на хостинг.

4. Передача данных третьим лицам

Сайт не продаёт и не передаёт персональные данные третьим лицам, за исключением следующих случаев:
